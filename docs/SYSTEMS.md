# Game Systems

Miner's Haven is built around interconnected gameplay systems that support resource collection, player progression, and exploration.

## Implemented Systems

### Mining System
Handles the core mining gameplay and interaction with resource deposits.

### Resource Collection
Supports collecting and managing resources obtained through mining.

### Artifact Discovery
Allows players to discover collectible artifacts with different rarity levels.

### Artifact Index
Tracks artifact discoveries and provides permanent progression bonuses.

### Inventory System
Manages resources and collected items.

### Selling System
Allows players to exchange collected resources for in-game currency.

### Pickaxe Progression
Supports equipment upgrades as players advance through the game.

### Island Progression
Connects player progression to access to new islands.

## Systems In Development

### Shop System
Planned to expand equipment and item purchasing.

### Minion System
Planned to introduce companion-based automated mining.

## Development Approach

The project focuses on building interconnected systems that support a consistent gameplay loop. Systems are developed and integrated alongside the game's environments and user interface.

*This document provides a high-level overview. Internal source code and implementation details are not publicly distributed.*
